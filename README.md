# Silene_SexRatio_Mechanisms
This repository contains the data and code used in a study examining the mechanisms maintaining gynodioecy in Silene acaulis. This README.md was updated 2026-05-06 by Emma K. Chandler.

## General Information
1. Data and R code: Hermaphrodite frequency and differential floral morphology maintains female advantage through pollination in a gynodioecious species
2. Author Information:

Emma K. Chandler, Department of Plant Biology, University of Georgia, ORCiD:0000-0002-6507-1091

Corresponding Author: Megan L. DeMarche, Department of Plant Biology, University of Georgia, ORCiD:0000-0002-5010-2721

3. Most of the data for the floral morphology observations, pollen deposition observations, and pollination experiment collected summer of 2024. Additional floral morphology data collected summer of 2025. Sex ratio of populations at Niwot Ridge surveyed in summer 2023 and 2024.
4. Data collected at the University of Colorado Boulder Mountain Research Station, Niwot Ridge.
5. Information about funding sources: This work was supported by NSF DEB 2413626 and logistical support was provided by the NSF-supported Niwot Ridge LTER program (NWT VII: NSF DEB – 1637686, NWT VIII: NSF DEB-2224439)

## Data and File Overview
A. File folder Programs: R scripts for data analysis
   1. Ovule_Count_2025.Rmd: data formatting and exploration for additional floral morphology data collected in 2025
   2. PollenDeposition_Final.Rmd: data analysis for floral morphology and pollen deposition data collected in 2024 and 2025
   3. PollinationExperiment_Final.Rmd: data analysis of pollination experiment conducted in 2024

B. File folder Raw_Data: folder with all data used in this project
   1. File folder Data: csv files with data for analysis
        - Filename  Ovule_Count_2025.csv: floral morphology data added in 2025
        - Filename Ovule_Count_2025_meta.csv: meta data for floral morphology added in 2025
        - Filename Pollen_Deposition.csv: meta data for floral morphology and pollen deposition data from 2024
        - Filename Pollen_Deposition_Data_all.csv: floral morphology and pollen deposition data from 2024
        - Filename Pollination_Experiment.csv: meta data for the pollination experiment in 2024
        - Filename Pollination_Experiment_Seeds.csv: data from a pollination experiment in 2024
        - Filename Sex_Ratio_2023.csv: sex ratio data from 2023
        - Filename Sex_Ratio_2024.csv: sex ratio data from 2024
   2. File folder Demography Plots Sex Ratio: Sex ratio data from plots that are a part of a long-term demography study at Niwot Ridge
   3. File folder Scans: scans of paper datasheets used to collect field data
